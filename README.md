Executando o Projeto:

pip install poetry taskipy poetry-plugin-shell

poetry shell <---# ativa o venv

task init

task run


OBS: o template de exibicao foi pensado para ser usado em tela cheia, caso pareca desconfigurado apenas aperte f11 na pagina

formatos suportados:

imagens = ['png', 'jpg', 'jpeg', 'gif', 'bmp', 'webp', 'svg', 'tiff'];
videos = ['mp4', 'webm', 'ogg', 'mov', 'avi', 'mkv', 'flv', 'wmv'];
